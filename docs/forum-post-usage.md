# 论坛帖子功能使用说明

## 一、功能概述

论坛帖子模块提供以下核心能力：

1. **帖子数据获取**：支持分页列表查询和详情查询
2. **点赞交互**：用户可对帖子进行点赞/取消点赞
3. **浏览量统计**：自动统计帖子浏览量，防止重复刷量

## 二、使用流程

### 2.1 查看帖子列表

用户进入论坛页面后，系统自动加载帖子列表：

1. 选择版块标签，筛选特定版块帖子
2. 列表默认按「置顶优先 + 发布时间倒序」排序
3. 滚动到底部自动加载下一页

### 2.2 查看帖子详情

点击帖子卡片进入详情页：

1. 展示完整标题、正文、图片等内容
2. 自动触发浏览量 +1（同一用户 30 分钟内不重复统计）
3. 展示当前浏览量、点赞数、评论数

### 2.3 点赞操作

在帖子列表或详情页点击点赞按钮：

1. 未点赞时：点赞数 +1，按钮高亮
2. 已点赞时：点赞数 -1，取消高亮
3. 后端通过数据库唯一约束防止重复点赞

## 三、技术实现说明

### 3.1 数据一致性

- 点赞记录存储在 `t_forum_like` 表
- 帖子点赞数通过 SQL 原子操作更新：`like_count = like_count + 1`
- 浏览量通过 SQL 原子操作更新：`view_count = view_count + 1`

### 3.2 防刷机制

| 场景 | 机制 | 有效期 |
|------|------|--------|
| 重复点赞 | 数据库唯一索引 + 状态字段 | 永久 |
| 刷浏览量 | Redis 缓存用户浏览记录 | 30 分钟 |
| 点赞状态查询 | Redis 缓存用户点赞状态 | 5 分钟 |

### 3.3 性能优化

- 帖子列表查询默认响应时间不超过 300ms，超过会打印告警日志
- 点赞和浏览量更新使用原子 SQL，避免并发问题
- Redis 缓存减少数据库查询压力

## 四、数据库表

### t_forum_post（帖子表）

| 字段 | 说明 |
|------|------|
| post_id | 帖子ID |
| author_id | 作者ID |
| board_id | 所属版块ID |
| title | 标题 |
| content | 正文 |
| status | 状态 |
| view_count | 浏览量 |
| like_count | 点赞数 |
| published_time | 发布时间 |

### t_forum_like（点赞表）

| 字段 | 说明 |
|------|------|
| id | 主键 |
| target_type | 目标类型：1-帖子 2-评论 |
| target_id | 目标ID |
| u_id | 用户ID |
| status | 状态：1-点赞 0-取消 |

## 五、日志记录

关键操作会记录 INFO 级别日志：

```
用户 100 点赞帖子 1
帖子 1 浏览量 +1
帖子 1 审核状态变更为 2
```
