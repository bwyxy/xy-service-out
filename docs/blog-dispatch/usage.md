# 博客多平台分发模块使用说明

## 1. 模块概览

博客多平台分发模块无缝嵌入现有 admin 文章中心，在不改动原有文章编辑、存储、管理逻辑的前提下，把一篇（或多篇）文章一次性分发到多个第三方博客平台，并统一回收运营数据。

| 能力 | 说明 |
|------|------|
| 平台配置管理 | 可视化配置各平台账号凭证、发布默认规则、长度/标签限制、限流与超时、可用角色 |
| 内容自动适配 | 标题/摘要长度裁剪、标签数量裁剪、HTML→Markdown、图片迁移与 URL 重写 |
| 异步分发 | 任务落库后交由线程池异步执行，不阻塞后台操作 |
| 全链路任务管理 | 任务状态、关联文章、目标平台、执行耗时、失败原因、一键/批量重试 |
| 数据聚合同步 | 回传平台文章访问链接，定时拉取浏览量/点赞/评论/收藏并聚合统计 |
| 权限与容错 | 按角色授权可用平台；异常归一化提示、限流降级、瞬时异常自动重试 |

已内置平台：**掘金、CSDN、知乎、微信公众平台、简书、开源中国**。新增平台无需改动业务流程，按适配器模式扩展即可（见部署指南第 7 节）。

## 2. 菜单入口

模块菜单挂在现有「文章管理」目录下，与文章中心同级：

| 菜单 | 路由路径 | 前端组件 | 权限串 |
|------|----------|----------|--------|
| 分发平台配置 | `dispatchPlatform` | `article/dispatch/platform/index` | `blog:dispatch:platform:list` |
| 分发任务 | `dispatchTask` | `article/dispatch/task/index` | `blog:dispatch:task:list` |
| 分发数据统计 | `dispatchStat` | `article/dispatch/stat/index` | `blog:dispatch:stat:view` |

按钮级权限：`platform:add / edit / remove / test`、`task:dispatch / retry / remove`、`stat:sync`。

## 3. 平台配置

进入「文章管理 → 分发平台配置」。

- 系统初始化时已写入 6 个平台，状态均为**禁用**，需配置凭证并启用后才可分发。
- 关键字段：

| 字段 | 说明 |
|------|------|
| 平台编码 | 唯一，必须与适配器 `platformCode()` 一致 |
| 是否启用 | 只有启用且已授权的平台才会出现在分发弹窗中 |
| 账号凭证 | 按平台动态渲染（见下表），**AES 加密后落库，永不回显明文** |
| 发布默认规则 | JSON 文本，如默认分类、默认标签、是否原创、是否存草稿 |
| 标题/摘要/正文最大长度、标签最大数量 | 内容适配层据此裁剪 |
| 每分钟最大请求数、请求超时、最大重试次数 | 限流与容错参数 |
| 可用角色 | 勾选后该角色才能使用该平台；超级管理员不受限制 |

各平台凭证字段：

| 平台 | 凭证字段 | 正文格式 | 图床上传 | 数据采集 |
|------|----------|----------|----------|----------|
| 掘金 juejin | `cookie` | Markdown | 否（降级到七牛） | 否 |
| CSDN csdn | `cookie` | Markdown | 否（降级到七牛） | 否 |
| 知乎 zhihu | `cookie` | HTML | 是 | 是 |
| 微信公众平台 wechat | `appId`、`appSecret` | HTML | 是 | 否 |
| 简书 jianshu | `cookie` | Markdown | 是 | 是 |
| 开源中国 oschina | `cookie` | Markdown | 是 | 是 |

操作说明：

- **编辑**：凭证输入框留空表示保持原有凭证不变，只有重新填写才会覆盖，避免误清空。
- **测试**：调用平台接口做连通性测试，结果与时间会记录在平台配置上。
- **删除**：删除后该平台历史任务仍保留，仅不再可分发。

> 安全说明：列表/详情接口均不下发凭证密文，只返回 `credentialConfigured` 布尔标记。

### CSDN 配置要点

CSDN 使用**真实适配器**实现（不走模板配置），无需填写接口地址，配置好 Cookie 即可分发：

1. 浏览器登录 `blog.csdn.net` → F12 → Network → 任意请求 → 复制 Request Headers 中 `Cookie:` 后的**整行**，填入凭证 Cookie。
2. Cookie 必须包含 `UserToken`、`UserName` 等登录态字段；过期后任务会以「凭证已过期」失败，重新复制即可。
3. 发布默认规则（JSON）支持以下字段，均可省略：

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `account` | CSDN 用户名，用于回传文章访问链接 | 空（不填则不回传链接） |
| `categories` | 分类专栏名称，**需已在 CSDN 后台创建** | 空 |
| `type` | 文章类型：`original` / `repost` / `translated` | `original` |
| `originalUrl` | 转载/翻译时的原文地址，缺省取自己博客的原文链接 | 空 |
| `readType` | 可见范围：`public` / `private` / `read_need_fans` / `read_need_vip` | `public` |
| `publishAsDraft` | `true` 时只保存为草稿，不直接公开 | `false` |
| `articleId` | 覆盖更新指定文章时填写其 Id | 空 |
| `publishUrl` | 覆盖默认发布接口地址，一般无需填写 | 内置地址 |

4. 接口调用会自动附带 `x-ca-key` / `x-ca-nonce` / `x-ca-signature` 签名头（每次请求随机生成 nonce 并重新计算 HMAC-SHA256 签名），无需人工干预。

### 掘金配置要点

掘金同样使用**真实适配器**实现，无需填写接口地址，流程为「创建草稿 → 发布草稿」两步：

1. 浏览器登录 `juejin.cn` → F12 → Network → 任意请求 → 复制 Request Headers 中 `Cookie:` 后的**整行**，填入凭证 Cookie（关键是 `sessionid`）。
2. 掘金要求**摘要不少于 50 字**且**至少一个标签**，适配器会自动处理：摘要不足 50 字时先从正文首段提取，仍不足则用标题补齐；超过 100 字截断；未配置任何标签则会直接失败并提示补充 `tagIds`。
3. 发布默认规则（JSON）支持以下字段：

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `categoryId` | 分类 Id（**字符串**），不填使用「人工智能」分类 | `6809637773935378440` |
| `tagIds` | 标签 Id 数组，**必填至少一个**；也支持逗号分隔字符串 | 无 |
| `original` | 是否声明原创 | `true` |
| `originalLink` | 转载时的原文地址 | 空 |
| `editType` | 编辑器类型，`10` 表示 Markdown | `10` |
| `publishAsDraft` | `true` 时只创建草稿不发布，回传草稿编辑地址 | `false` |
| `syncToOrg` | 发布时是否同步到团队/专栏 | `false` |
| `publishUrl` / `articlePublishUrl` | 覆盖默认接口地址，一般无需填写 | 内置地址 |

4. 常用分类 Id：后端 `6809637769959178254`、前端 `6809637767543259144`、人工智能 `6809637773935378440`、开发工具 `6809637771511070734`、代码人生 `6809637776263217160`。
5. 常用标签 Id：Java `6809640445233070094`、Spring `6809640703325372423`、Spring Boot `6809641037787561992`、Vue.js `6809640369764958215`、JavaScript `6809640398105870343`、MySQL `6809640366896054286`、Redis `6809640371019055111`、Docker `6809640396788858887`。更多标签可用掘金的标签搜索接口按名称查询。
6. 正文图片统一走自有七牛图床（掘金图床接口为 token + 对象存储直传，未接入）。
7. 封面：掘金要求封面必须来自其自有图床（`byteimg.com` 域名），外部地址会被参数校验以「参数错误」拒绝，因此发布规则不会携带外部封面，文章发布后可在掘金编辑器里手动设置封面（正文首图通常会被掘金自动采纳）。

## 4. 发起分发

两个入口，均复用同一个分发弹窗：

1. **文章列表页**：操作列点「分发」= 单篇分发；勾选多篇后点工具栏「批量分发」= 多篇分发。
2. **文章编辑页**：底部「分发到第三方平台」按钮（文章需已保存，否则提示先保存）。

弹窗行为：

- 只展示**当前登录人可用**的平台（已启用 + 有角色权限 + 有适配器实现），并标注「已配置凭证 / 未配置凭证 / 无适配器」。
- 「忽略已分发」开关默认开启：已成功分发过的文章不会重复提交到同一平台。
- 提交后返回：批次号、新建任务数、跳过数，以及逐条跳过原因。

支持 **多篇 × 多平台** 组合，例如 3 篇文章勾选 2 个平台会生成 6 个任务，共用同一个批次号，便于回溯。

## 5. 分发任务管理

进入「文章管理 → 分发任务」。

任务状态：

| 状态值 | 含义 |
|--------|------|
| 0 | 待分发 |
| 1 | 分发中 |
| 2 | 分发成功 |
| 3 | 分发失败 |

列表支持按文章标题、平台、状态筛选；通过多选框可**批量重试**、**批量删除**。

- **详情**：展示批次号、状态、重试次数、执行耗时、平台文章链接、错误类型与错误信息、是否需要人工处理、是否可重试。
- **重试**：把失败任务重置为待分发并重新入队；已成功或正在执行的任务会被自动跳过。
- **自动重试**：仅对瞬时异常（网络异常、平台限流、平台接口异常等）按间隔自动重试，达到最大重试次数后停止。
- **兜底扫描**：定时扫描滞留的待分发任务重新入队，避免线程池繁忙导致任务长期不执行。

## 6. 运营数据统计

进入「文章管理 → 分发数据统计」。

- 顶部为**按平台聚合**的汇总（文章数、浏览量、点赞、评论、收藏等）。
- 下方为**文章明细**，支持按关键字、平台筛选。
- 分发成功时会自动回传平台访问链接并写入一条运营数据记录（初始为 0）。
- 定时任务按 `dispatch.stat.cron`（默认每天 02:00）拉取各平台数据；也可点「立即同步数据」手动触发，返回本次更新的记录数。

## 7. 内容适配与图片迁移规则

分发前由内容适配层自动处理，原始文章内容不受影响：

1. **标题/摘要**：超过平台限制时按字符截断并记录告警日志；摘要为空时自动取正文纯文本。
2. **标签**：去重后按平台标签上限裁剪。
3. **正文格式**：需要 Markdown 的平台做 HTML→Markdown 转换；需要 HTML 的平台使用富文本，并清理 `script`/`style` 等不安全标签。
4. **长度校验**：标题或正文为空 → 内容违规；正文超过平台上限 → 内容超长，均在任务中以明确错误类型呈现。
5. **图片迁移**：优先上传到目标平台官方图床并重写图片地址；不支持或失败时，非 HTML 平台降级到自有七牛图床；两者都失败则保留原地址并记录明细，**不会因个别图片失败导致整篇分发失败**。

## 8. 错误类型与处理建议

| 错误类型 | 提示 | 可自动重试 | 需人工处理 |
|----------|------|-----------|-----------|
| NONE | 无异常 | - | - |
| CREDENTIAL_INVALID | 平台凭证未配置或无效，请检查账号配置 | 否 | 是 |
| CREDENTIAL_EXPIRED | 平台凭证已过期，请重新配置账号凭证 | 是 | 是 |
| RATE_LIMITED | 触发平台接口限流，请稍后重试 | 是 | 否 |
| CONTENT_VIOLATION | 内容未通过平台审核，请修改后重试 | 否 | 是 |
| CONTENT_TOO_LARGE | 内容长度超出平台限制，请精简后重试 | 否 | 是 |
| DUPLICATE_CONTENT | 平台已存在相同内容，请勿重复分发 | 否 | 是 |
| NETWORK_ERROR | 调用平台接口网络异常，请稍后重试 | 是 | 否 |
| PLATFORM_ERROR | 平台接口返回异常，请稍后重试或联系平台 | 是 | 否 |
| ADAPTER_NOT_FOUND | 未找到该平台的适配器实现 | 否 | 是 |
| PLATFORM_DISABLED | 该分发平台未启用，请先在平台配置中开启 | 否 | 是 |
| PERMISSION_DENIED | 当前账号无权使用该分发平台 | 否 | 是 |
| CONCURRENT_CONFLICT | 任务正在执行中，请勿重复提交 | 是 | 否 |
| UNKNOWN | 分发失败，未知异常 | 是 | 否 |

## 9. 常见问题

**Q：为什么分发弹窗里没有我想选的平台？**
平台必须先「启用」，且当前账号所属角色被授予该平台权限；若平台无适配器实现，选项会置灰。

**Q：为什么提示"请先保存文章，再分发到第三方平台"？**
编辑页分发依赖文章 Id，未保存的新文章没有 Id，请先保存。

**Q：凭证为什么看不到明文？**
凭证 AES 加密存储、接口脱敏返回。需要更换时在编辑页重新填写即可。

**Q：任务一直停在「待分发」？**
线程池繁忙或应用重启会导致短暂滞留，兜底扫描会定时重新入队；若长期不动，请检查应用日志与线程池状态。

**Q：第三方平台是非官方接口，会受影响吗？**
除微信公众平台使用官方草稿箱接口外，其余平台均通过 Cookie 走非官方接口，平台前端改版可能导致接口失效，此时任务会以 `PLATFORM_ERROR` 等类型失败并给出提示，需要相应更新适配器实现。
